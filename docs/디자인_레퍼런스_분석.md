# 디자인 레퍼런스 분석 (2026-11-10)

참고 자료: 사용자가 대화에 첨부한 물류 대시보드 스크린샷 1장(dribbble 출처 표기, "Logivo" 가상 브랜드, "Central Distribution Hub - Zone A").
이미지 파일 자체는 프로젝트에 저장되어 있지 않으며, 아래는 그 화면에서 실제로 보이는 요소만 적었다.

## 1. 화면에서 확인되는 구조

| 영역 | 보이는 내용 |
|---|---|
| 바깥 캔버스 | 채도 낮은 세이지(연녹색) 배경 위에 큰 라운드 컨테이너 하나 |
| 상단 | 좌측 로고, 가운데 알약(pill) 탭 메뉴 5개(Overview 활성 = 흰 알약), 우측 원형 아이콘 버튼 2개 |
| 헤더(히어로) | 어두운 사진 배경 위 위치 라벨(작은 글씨) + 큰 2줄 제목(흰색) + 우측 알약 버튼 2개(밝은 것·검은 것) |
| 1행 카드 3개 | ① 일정 목록(시간 알약 + 이름·경로 + 우측 보조값) ② 아이콘 원 + 값 + 설명의 2×3 지표 묶음 ③ 추세 차트(면 영역 + 강조 지점 배지 + 점선 기준선) |
| 2행 카드 3개 | ① 2×2 타일(로고·평점) ② 키-값 목록 + 검은 주 버튼 ③ 아바타 목록(이름·역할·평점·우측 보조값) |
| 카드 공통 | 큰 라운드(약 20px), 흰색에 가까운 면, 테두리 거의 없음, 제목(굵게) + 보조 설명(작은 회색) + 우측 원형 화살표(↗) 버튼 |
| 색 역할 | 중립(검정·회색 글자, 흰 면), 포인트 1색(주황)은 로고·별점·차트 강조·아이콘에만 소량, 주 버튼은 검정 |
| 밀도 | 카드 안 여백 넉넉(약 20~24px), 카드 사이 간격 일정(약 12~16px), 한 화면에 카드 6장 |

## 2. 적용한 원칙 (다품종 3PL 대시보드 기준)

| 레퍼런스 원칙 | 적용 방법 |
|---|---|
| 캔버스 + 라운드 카드 | 연한 청록 회색 캔버스(`--canvas`) 위에 흰 카드(`--radius-card` 18px). 모든 화면의 섹션이 같은 카드 규칙을 따름 |
| 어두운 헤더(히어로) | 사진 대신 기존 차콜(#193342) 헤더 카드: 화면 번호·제목·가상 데이터 배지·필터·적용 범위를 한곳에 모음 |
| 카드 헤더 = 제목 + 보조 + ↗ | `UI.card()` 공통 부품. ↗는 관련 상세 화면으로 실제 이동(`data-go`) |
| 1행 = 핵심 숫자 + 할 일 목록 | 개요: 왼쪽 2칸 공통 KPI 6개, 오른쪽 1칸 "지금 확인할 일"(우선순위 알약 = 레퍼런스의 시간 알약 역할) |
| 아이콘 원 + 값 + 설명 묶음 | 개요의 "인력 운영" 카드(기간 평균 인원·임시 인력·연장 시간) — 기존 계산값 그대로 |
| 추세 차트 카드 | 기존 주별 주문·출고 차트를 넓은 카드에 배치(차트 종류·계산 그대로) |
| 알약 메뉴·활성 표시 | 사이드바 메뉴를 알약 모양으로, 활성 화면은 강조색 면 + 굵은 글씨. 모바일은 드로어 |
| 포인트 색 소량 사용 | 기존 강조색(청록 #0B7067 / 어두운 면 위 #7FD1C3)만 사용. 상태색(정상·주의·위험)은 기존 그대로 |

## 3. 의도적으로 적용하지 않은 것

- **사진 히어로·트럭 이미지**: 가상 데이터 대시보드에 장식 사진은 정보가 아니므로 쓰지 않음
- **주황 포인트색**: 포트폴리오 공통 색(차콜·청록)과 각 사이트 고유 강조색(SCM 파랑 등)을 유지
- **아바타·평점·로고 타일·검은 승인 버튼**: 대응하는 실제 데이터·기능이 없음. 없는 데이터로 비슷한 카드를 만들지 않음
- **상단 가로 탭 메뉴**: 화면이 10개라 가로 탭은 넘침 → 사이드바(PC)·드로어(모바일) 유지
- **면 빗금 차트·강조 배지**: 기존 차트 종류와 데이터에 맞지 않아 새로 만들지 않음

## 4. 적용 범위

- 적용: 다품종 3PL 데모(`demos/scm-dashboard/`) 전 화면, 메인 Flask 홈의 KPI·대표 프로젝트 그리드(채용용 구성 유지), 신규 Jekyll 홈 카드·그리드
- 적용(2026-11-11 추가): ScmData·WarehouseOps `ops/` 전 화면. 세 곳은 같은 엔진(`charts.js` 동일, `ui.js` 8줄·CSS는 강조색만 다름)이라 3PL과 같은 카드 부품·드로어·CSS 레이어를 이식했다.
  - 강조색 보존: ScmData 파랑(#2F5BA0, 캔버스 #E6ECF4), WarehouseOps 청록(3PL과 동일)
  - 개요 오른쪽 카드: WarehouseOps는 3PL과 같은 "인력 운영", ScmData는 인력 화면이 없으므로 기존 정산 계산값(실적 기준·정산 초안·차이)을 쓰는 "정산·주문 점검"
  - SAMPLE DATA 배지는 두 사이트의 기존 점검 기준(`.demo-flag .sample-badge`)에 맞춰 안내 띠 안에 둠
  - 계산 파일(`data.js`·`metrics.js`·`charts.js`·`export.js`)은 수정하지 않음
- 비적용: REBOOT·AXPORT 브랜드 화면, PDF·PPT 레이아웃(대시보드 캡처 이미지만 새 화면으로 갱신)
